# Shiny Portfolio App

This is a portfolio web application built with R and Shiny, styled with Materialize CSS.

## How to Run

1.  Ensure R is installed.
2.  Install the `shiny` package:
    ```r
    install.packages("shiny")
    ```
3.  Run the app:
    ```r
    shiny::runApp()
    ```

## Structure

-   `app.R`: The main application file containing both UI and Server logic.
